# Xitcoin Token Assets

Official visual assets for Xitcoin (XTC).

This repository is limited to the token symbol and its approved color variants. It does not define website typography, interface styles or product layouts.

## Asset selection

| Use | File |
| --- | --- |
| General-purpose vector | `assets/svg/xitcoin-symbol.svg` |
| Single-color vector for dark backgrounds | `assets/svg/xitcoin-symbol-white.svg` |
| Wallets, explorers and token lists | `assets/png/standard/` |
| Dark-background raster use | `assets/png/white/` |

SVG is the preferred format whenever the integration supports vector artwork. PNG files are provided at fixed pixel sizes for platforms that require raster assets.

## Official colors

| Role | Hex |
| --- | --- |
| Xitcoin Orange | `#FB8D00` |
| Xitcoin Graphite | `#53585E` |
| White | `#FFFFFF` |

The standard symbol uses Xitcoin Orange and Xitcoin Graphite. The white variant is intended only for dark backgrounds.

## Usage

- Preserve the symbol's aspect ratio.
- Keep sufficient clear space around the symbol.
- Do not redraw, rotate, stretch or recolor the artwork.
- Do not place the standard symbol on a background that reduces contrast.
- Use the supplied files as the source of truth.
